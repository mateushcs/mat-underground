# Uptime Center — processo de design

Quatro diagramas para comunicar a contribuição de Mat: investigação, jornadas e protótipos, descoberta sobre contexto de uso, validação e entrega.

As sequências sintetizam um processo iterativo, não uma cronologia rígida. Baseadas no relato de Mat e na análise do acervo, sem reproduzir regras de negócio, integrações específicas ou procedimentos internos do cliente.

Abra `index.html` para a prévia. Os SVG são vetoriais e os `.mmd` são fontes editáveis Mermaid. `build_flows.py` regenera ambos. Os nomes dos arquivos foram mantidos para atualizar os links existentes; seu conteúdo agora descreve somente o processo de design.

Esta revisão substitui os fluxogramas operacionais anteriores. Os materiais originais de pesquisa permanecem fora desta apresentação. Nada foi publicado no site.
